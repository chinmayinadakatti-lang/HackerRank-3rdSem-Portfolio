## About This Portfolio

This repository contains my solutions to the five mandatory HackerRank problem-solving challenges completed as part of my 3rd Semester portfolio activity. The solutions are implemented in C++ and focus on efficient algorithms, problem-solving, and complexity optimization.

## Problems Completed

### 1. Diagonal Difference

- [Solution](./01-Diagonal-Difference/solution.cpp)
- **Approach:** Calculate the sum of the primary and secondary diagonals in one traversal and return their absolute difference.
- **Time Complexity:** O(N)
- **Extra Space:** O(1)

### 2. Dynamic Array

- [Solution](./02-Dynamic-Array/solution.cpp)
- **Approach:** Use a collection of dynamic sequences and calculate the required sequence index using XOR with the previous answer.
- **Time Complexity:** O(N + Q)
- **Space Complexity:** O(N)

### 3. Time Conversion

- [Solution](./03-Time-Conversion/solution.cpp)
- **Approach:** Convert the 12-hour time format into 24-hour format by handling AM and PM cases.
- **Time Complexity:** O(1)
- **Space Complexity:** O(1)

### 4. Compare the Triplets

- [Solution](./04-Compare-the-Triplets/solution.cpp)
- **Approach:** Compare Alice's and Bob's scores position by position and count their respective points.
- **Time Complexity:** O(1)
- **Space Complexity:** O(1)

### 5. Sparse Arrays

- [Solution](./05-Sparse-Arrays/solution.cpp)
- **Approach:** Store the frequency of each string using an unordered map and use it to answer each query efficiently.
- **Time Complexity:** O(N + Q) average
- **Space Complexity:** O(N)
